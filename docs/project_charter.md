# Project Charter

## 목적

MATLAB/Simulink와 Simscape Electrical을 사용해 계통연계형 태양광 발전 시스템을 작은 단위로 구현하고, 각 전력변환 단계와 제어 루프의 물리적 의미를 설명할 수 있는 수준까지 학습한다.

## 최종 목표

- 약 1 MW급 PV array 구성
- P&O MPPT와 boost converter 연동
- DC-link 전압 제어
- 3상 계통연계 인버터와 abc-dq 전류 제어
- 필터, 변압기, 계통 및 로컬 부하 통합
- 일사량 변화에 대한 정상상태 및 과도응답 분석
- 재현 가능한 코드, 모델, 결과 및 학습 기록을 포트폴리오 형태로 정리

## 진행 원칙

1. 한 번에 한 STEP만 구현하고 사용자가 MATLAB/Simulink에서 직접 실행·검증한다.
2. 파라미터에는 의미와 단위를 명시하고 계산은 가능한 한 스크립트로 분리한다.
3. 제어 subsystem의 입력, 출력, 정상 동작 조건과 진단 항목을 문서화한다.
4. 완료되지 않은 기능이나 검증하지 않은 결과를 완료된 것처럼 표현하지 않는다.
5. 변경 범위에 맞는 최소 검증을 수행하고 통합 시점에 전체 검증을 수행한다.

## 범위

포함 범위는 PV array, MPPT, boost converter, DC-link, 계통측 인버터, 좌표변환, PI 제어, PWM, 필터, 변압기, 계통/부하 및 결과 분석이다.

현재 STEP 0의 범위는 저장소 초기화, 폴더 구조, 환경 확인, 프로젝트 설정 및 기본 문서 작성까지이다. 전력회로 및 제어 모델 구현은 포함하지 않는다.

## 산출물 기준

- R2025a 기준으로 실행 가능하며 가능한 범위에서 R2024b 호환 API 사용
- 필요한 Toolbox와 실행 방법을 README에 기록
- 모델 입력·출력과 주요 파라미터의 단위 기록
- 직접 생성한 결과만 `results/`에 사용
- 교수 제공 자료 원본 및 복제 콘텐츠는 Git에 포함하지 않음

## 완료 조건

STEP 0은 저장소 구조가 생성되고, `setup_project.m`과 `check_environment.m`이 명확한 진단 메시지를 제공하며, Git 상태에서 의도한 초기 파일만 추적 대상으로 나타날 때 완료된다.
